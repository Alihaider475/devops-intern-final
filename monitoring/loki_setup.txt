Grafana Loki Setup
==================

1. Loki was started using Docker:

docker run -d --name loki -p 3100:3100 grafana/loki:latest

2. Loki is available at:

http://localhost:3100

3. Loki health was checked using:

http://localhost:3100/ready

4. The response was:

ready

5. Loki container status was checked using:

docker ps

6. Loki logs can be viewed using:

docker logs loki
